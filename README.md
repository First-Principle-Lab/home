## Research

### TypyBench experiments

Exploring when a language model should retrieve code memory during Python type inference, and how selective retrieval affects accuracy and token cost. These experiments build on the original [TypyBench benchmark](https://github.com/typybench/typybench).

[Explore the experiments](https://github.com/First-Principle-Lab/typybench)

### ExpeRepair

Exploring memory-based program repair with LLM agents. The framework stores repair experiences and retrieves them for future issues. The lab repository is a fork of [ExpeRepair](https://github.com/ExpeRepair/ExpeRepair).

[Explore the repository](https://github.com/First-Principle-Lab/ExpeRepair)
